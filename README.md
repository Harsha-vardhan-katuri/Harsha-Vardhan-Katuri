# 💫 About Me

I'm a **Firmware Engineer** with around **1.6 years of experience** developing and debugging embedded firmware, middleware, and hardware-integrated systems.

My primary focus is **Embedded C/C++, Embedded Linux, hardware-firmware integration, communication protocols, and low-level debugging**.
